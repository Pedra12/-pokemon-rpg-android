# Arquivos de origem do RPG Android

Este repositório guarda os arquivos enviados durante a montagem do jogo: pacotes gráficos Clover Valley, o projeto Android vertical original e arquivos de referência.

## Repositório ativo do APK

A compilação e as melhorias atuais estão em:

https://github.com/Pedra12/-pokemon-rpg-android.

Abra **Actions** nesse segundo repositório e execute **Build Aventura Elemental Android APK** para gerar o APK Debug.

## Arquivo principal do projeto Android

`pokemon-rpg-android-clover-valley-map.zip` contém o protótipo Android vertical em Kotlin/Jetpack Compose que usamos como base para Aventura Elemental.

## Observação sobre o arquivo PokeRPG

`PokeRPG-main.zip` é um projeto de terceiros. O LICENSE incluído declara todos os direitos reservados e não concede permissão para copiar, modificar ou redistribuir. Ele não é usado na compilação do nosso jogo.

## Assets

Os arquivos Clover Valley foram fornecidos pelo usuário. O pacote não inclui uma licença completa no ZIP; confirme os termos do autor antes de publicar ou redistribuir o jogo.
